# 3.1 Area and marker system

## Steps
1. [ ] Define the marker naming convention (`ref<Name>`, `interact<Name>`, `spawn<Name>`) in `docs/`.
2. [ ] Load each area GLB and create its `Area` subclass from `Areas.js`.
3. [ ] Remove old folio areas (bowling, circuit, toilet, cookie...) not in the new design.
4. [ ] Zones for entering/leaving an area (music/lighting changes later).
