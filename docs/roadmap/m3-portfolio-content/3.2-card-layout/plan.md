# 3.2 Card layout and style

**Goal:** the cards look like part of the festival: light, warm, readable.

**Files:** `sources/style/*.styl`, `sources/index.html`.

## Steps
1. [ ] One shared card style: cream paper background, sakura-pink accents, dark readable text.
2. [ ] Layouts: About (text + photo), Experience (timeline), Skills (grouped tags), Projects (image cards with links), Contact (big buttons).
3. [ ] Mobile layout: full-screen card, scrollable, large close button.
4. [ ] Links open in a new tab; the game keeps running behind the card.

## Done when
- [ ] All 5 cards are readable on desktop and a phone screen.
