# 2.1 Layout blockout

## Steps
1. [ ] Sketch a top-down map (paper or Excalidraw): spawn, path, stream, bridge, torii, hill.
2. [ ] Blender: block the area with cubes/planes at real scale; place empties for spawn and markers (`refSpawnLanding`, `refInteract...`).
3. [ ] Export as `static/areas/entrance.glb`; load it and spawn Rei at the spawn empty.
4. [ ] Fly through: check scale relative to Rei and camera framing from the main viewpoints.
5. [ ] Repaint `terrain.png` to match the layout (path, stream bed).

## Done when
- [ ] Flying the path with grey boxes already feels like the concept composition.
