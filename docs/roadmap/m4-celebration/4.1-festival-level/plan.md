# 4.1 Festival level

**Goal:** one shared value says how festive the world is.

**Files:** `sources/Game/World/Lanterns.js` (or a tiny `Festival.js`).

## Steps
1. [ ] Add `festival` (0–1) plus a TSL `uniform` copy for shaders.
2. [ ] On each `lit` event, tween it up by 0.2 with GSAP over ~2 s.
3. [ ] On load, set it directly from the saved lit count.
4. [ ] Add a `#debug` slider to preview any level.

## Done when
- [ ] The debug slider moves the value and other systems can read it.
