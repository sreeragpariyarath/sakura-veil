# M5: Rei

**Postponed:** the Rei model is being reworked by the owner. Resume when the new GLB is ready.

Rei is a hooded floating spirit: dark cloak with sakura/wave pattern, ragged hem, pink-to-cyan glowing sleeves and hem, glowing cyan eyes, red talisman with tassel. No skeleton is needed: the cloak motion is done in a vertex shader, which avoids needing an animator.
